Research

NLP

Comprehensive Plagiarism Detection in Malayalam Texts

An application that checks Malayalam scholarly writing for plagiarism against web content. Malayalam is a low-resource language with few tools of this kind, so the paper compares four text-matching algorithms to find the most reliable one.

  • Compared SequenceMatcher, N-Grams, Rabin-Karp and Cosine Similarity
  • Cosine Similarity detected plagiarism best, at a 92.45% rate
  • Submit text, analyse it and review the results interactively
